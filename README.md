# Terminal Portfolio

وب‌سایت پورتفولیو ترمینالی دوزبانه (فارسی/انگلیسی) با طراحی خط فرمان تعاملی.

A bilingual Persian/English terminal-style portfolio website with an interactive command-line interface.

## 🔗 لینک آنلاین / Live Demo

**[https://amirreza4710.github.io/terminal-portfolio/](https://amirreza4710.github.io/terminal-portfolio/)**

## ✨ امکانات / Features

- **دوزبانه / Bilingual**: فارسی (RTL) و انگلیسی (LTR) با تاریخ شمسی/میلادی
- **ترمینال تعاملی / Interactive terminal**: دستورات قابل تایپ با خروجی زنده
- **اسکیل‌ها / Skills**: نمایش درصد مهارت‌ها با میله‌های پیشرفت رنگی
- **پروژه‌ها / Projects**: کارت‌های پروژه با لینک و status
- **تم‌ها / Themes**: چند تم رنگی قابل تغییر
- **اطلاعات تماس / Contact**: لینک‌های مستقیم و کپی کلیپ‌بورد
- **CTA مشاوره / Consultation CTA**: دکمه اقدام برای مشاوره رایگان هوشمندسازی کسب‌وکار
- **تاریخ محلی / Local date**: ساعت و تاریخ به وقت کاربر

## 🚀 اجرای محلی / Local Run

فایل index.html را در مرورگر باز کنید:

`ash
start index.html
`

یا از یک سرور ساده استفاده کنید:

`ash
python -m http.server 8000
`

سپس http://localhost:8000 را باز کنید.
